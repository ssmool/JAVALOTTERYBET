📁 Project Overview:

JAVALOTTERYBET is a Java-based software for generating smart betting suggestions for lottery-type games with number grids of up to 60 numbers. It offers both backend logic and a frontend window manager using Java Swing, powered by Java 2 Software Development Kit (JDK) and executed via the Java Virtual Machine (JVM).

This repository includes:

⚙️ backend/: Source code written in Java SE (J2SE) for lottery number processing.

🎨 frontend/: A GUI (Graphical User Interface) using Java Swing window manager components.

🚀 /bin/: A compiled .jar version of the project, ready to run with:

```bash
java -jar "ApostaCerto.jar"
```

🚀 Quick Start
1. Clone the Repository
```bash
git clone https://github.com/ssmool/JAVALOTTERYBET/
cd JAVALOTTERYBET
```
2. Run the Precompiled .jar File
Inside the /bin directory, simply run:

```bash
java -jar "ApostaCerto.jar"
```

Make sure you have Java JDK 8+ installed.
